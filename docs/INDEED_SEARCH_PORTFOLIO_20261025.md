## Rules for selection
- Start with six IT/bridge proven anchors and small samples from nontechnical families (20 listings each); do **not** call untested URLs optimal.
- Compare unique eligible leads per search and per 100 examined; exclude repeat identities from yield numerator.
- Eligibility is not a score derived from titles: read full description and check mandatory qualifications, compatible location/remote conditions, salary where stated, terms and outlook.
- Use one bilingual broad discovery lane so that adjacent occupations not represented here remain discoverable.
- Do not auto-save, auto-apply or change production searches without user-approved `-Apply`.
- LinkedIn is a separate second phase; retain same scoring, never reuse Indeed URL syntax.
