### Follow-up checks before implementation
- Capture status vs imported verified Posting count vs successfully saved artifacts must be independently asserted from backend receipts.
- Human states/preferences cannot be replaced by external AI exchange imports without explicit policy and tests.
- User-visible partial-success and archived-data messaging must reflect durable DB state, not browser widget state.
- Favor small UI improvements after backend source of truth is clarified; no generically repeated QA runs.
