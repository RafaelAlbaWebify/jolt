## Cross-component review

- **Data integrity:** no code was executed against an operator database. The main uncertain behavior is whether `list_opportunity_workbench(session)` has intended side effects that affect readiness export; trace before changing.
- **Exports:** duplicated full in-memory ZIP construction can create high peak memory and may leak raw data if packs are shared. A cryptographic SHA-256 manifest is integrity metadata, not confidentiality protection.
- **Legacy API surface:** distinguish deprecated-but-live import from intentionally blocked import. Investigate existing consumers before decommissioning.
- **Certification safety:** never rely on a test-looking filename as sole proof a database is disposable; add non-destructive tests with adversarial paths and a production-like copy.
- **Status semantics:** observed, pending, verified, rejected, exported, and imported are different states and must not be conflated.
