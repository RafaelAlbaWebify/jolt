## Change-phase priorities

1. **UX-01** protect multi-section import from partially persisted success without a receipt.
2. **AI-01** decide whether AIReview imports are intentionally mutable snapshots; if history matters, add versioned immutable revisions, while preserving human decisions.
3. **RI-01** surface quarantined pending postings and preserve fail-closed provenance.
4. **DB-01** review Alembic migration/backup sequence and concurrency on disposable SQLite; no migrations on user's live DB merely for audit.
5. **EX-02** avoid silently resetting malformed feedback index.
